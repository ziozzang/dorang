Every control above calls the same administration route a script calls — {{.APIBase}}/key/generate, /key/rotate, /key/update, /key/block and the rest — with this session's operator as the actor, so each one writes the audit row and publishes the invalidation (§11.2c) that the API does. Edit opens a form prefilled with the key's current fields: it is the key's whole desired state, so a box left as it is keeps its value and a box you empty resets that field. That is what makes a form safe here where it once was not — there is no “leave alone” state to confuse with “set to nothing”.
