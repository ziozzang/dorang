What is now true about this browser

Putting a secret on a screen puts it in places dorang cannot reach into and withdraw. This value is in this page's DOM; in this tab's back/forward cache, so a back navigation can redraw it; in whatever your browser writes for session restore; and in any screenshot, screen share or recording of this window. Browser extensions with access to page content can read it. So can anyone standing behind you.

That is the cost of minting a credential from a browser instead of from a terminal, and it is not a defect in this page — it is the trade the operator made when the UI was given this button. Copy the value into your secret manager now and close this tab. Do not paste it into a chat, a ticket or a shell that keeps history.
